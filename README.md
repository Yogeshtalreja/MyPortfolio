# Yogesh — Portfolio

Personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Animated loading screen with letter reveal
- Interactive line-wave canvas hero background
- Text-stroke hover animation on name
- Grayscale-to-color photo transition
- Vertical timeline for experience
- Particle network animation
- Scroll-triggered fade animations
- Scroll progress indicator
- Fully responsive design

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (Special Gothic Expanded One, Inter)
- Font Awesome 6.5 icons
- Canvas API for animations

## Setup
Simply open `index.html` in a browser, or deploy to GitHub Pages.

## Deployment (GitHub Pages)
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **main** branch, root `/`
4. Your site will be live at `https://<username>.github.io/<repo-name>/`
